# Project DNA — EIXO Piloto 01

**Estado:** DRAFT · **Versão:** 0.1.0 · **Perfil:** LITE.

> Todas as decisões de marca abaixo são **hipóteses demonstrativas** para testar o processo; não existe cliente real nem aprovação para executar UX/UI/Dev ou publicar.

## 1. Instruções e objetivos
- **Cliente fictício:** Ateliê Bruma, ateliê de cerâmica autoral.
- **Objetivo:** avaliar delegação e handoffs entre seis agentes para uma landing page.
- **Público (hipótese):** interessados em design e peças artesanais.
- **Jornada P0:** entender a proposta → explorar coleção fictícia → localizar seção de contato.
- **CTA:** “Conhecer a coleção”, navegação local na mesma página.
- **Fora do escopo:** dados reais, e-commerce, checkout, domínio, deploy, WhatsApp e pagamentos.

## 2. Contexto do projeto
- O UX Architect deve estruturar jornada, arquitetura e critérios mensuráveis.
- O UI Designer & Art Director deve propor direção de arte **específica para a marca**, tipografia, tokens, estados e responsividade; não reutilizar a marca EIXO.
- Conteúdo e imagens demonstrativos devem ser claramente identificáveis; não criar depoimentos fictícios apresentados como verdade.
- Nenhum Figma ou asset foi aprovado.

- **GitHub privado:** `mullz013/eixo-piloto-01`.
